# حالة المشروع — v0.2.0 (2026-10-30)

## اللي اتعمل ومتجرب

| الجزء | المحتوى | متجرب إزاي |
|---|---|---|
| الأساس (1) | الهوية وMFA بتطبيق أو بواتساب، العزل بين الشركات، الصلاحيات، التدقيق، Idempotency، Outbox، نواة المحاسبة | اختبارات |
| التهيئة (2) | الشركة والفروع، الخدمات والأسعار بتاريخ، الموظفين، العملاء وأولادهم، الباقات والحدود، دومين لكل شركة | اختبارات + متصفح |
| التشغيل (3) | الحجز والطابور، الكاشير، الفواتير والآجل والمرتجع، الصندوق بفئات العملة، القيود الأوتوماتيك | اختبارات + متصفح + السيرفر التجريبي |
| المخزون والولاء (4) | المخزون بالمتوسط، المشتريات، الباقات، الكوبونات، النقاط، العمولات، البقشيش، مواعيد الموظفين | اختبارات + متصفح + السيرفر التجريبي |
| المحاسبة (5) | المصروفات والمستحقات، الأصول والإهلاك، تسويات الكي نت، قائمة الدخل والميزانية، إقفال الفترة والسنة، النسخ الثابتة | اختبارات + متصفح + السيرفر التجريبي |
| الواتساب (6) | رقم لكل صالون، كود الدخول، رسايل الحجز والتذكير والفاتورة | اختبارات ببوابة وهمية (الإرسال الحقيقي مستني المفتاح) |
| وزارة التجارة (7) | القوائم الأربعة بأكواد XBRL، ربط الحسابات، 5 فحوص، CSV، نسخ ثابتة | اختبارات + متصفح |
| بدون إنترنت (8) | الكاشير يكمل من غير نت، إيصالات موقّعة، إرسال أوتوماتيك، مراجعة | اختبارات (منها تزامن حقيقي) + متصفح + السيرفر التجريبي |
| لوحة المنصة | الرئيسية، الشركات، فواتير الاشتراكات، الدعم، طلبات التواصل، الباقات، الإعدادات، عرض كدعم فني | اختبارات + متصفح + السيرفر التجريبي |
| الموقع العام | الأسعار، المميزات، طلب التواصل | متصفح (كمبيوتر وموبايل) |
| التقارير واللوحات | رئيسية الفرع، لوحة الشركة، التقارير ومقارنة الفروع، الإعدادات والتصدير | اختبارات + متصفح + السيرفر التجريبي |
| تطبيق العملاء (Flutter) | دخول بالواتساب، حجز، أقرب فرع، حجوزاتي، الأطفال، النقاط والباقات | تحليل واختبارات Flutter في CI |

## مستني صاحب المشروع

| البند | ليه |
|---|---|
| مفتاح Evolution العام (`AUTHENTICATION_API_KEY`) | إرسال الواتساب الحقيقي وحجز العملاء |
| حسابات Google Play وApple وFirebase | رفع التطبيق على المتاجر والإشعارات |
| مزود الدفع | الدفع الأونلاين في التطبيق والاشتراكات |
| محاسب | اعتماد القيود والسياسات (D-011) وتصنيف التدفقات |
| مراقب حسابات | قبل رفع أي قوائم لوزارة التجارة |
| إلغاء توكن Coolify القديم | كان مكتوب في المحادثة |
