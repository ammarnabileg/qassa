# تقرير المرحلة 2 — التهيئة

## ما تم تنفيذه (مختبر)

| البند | التنفيذ | الدليل |
|---|---|---|
| تسجيل شركة بكيان وفروع وباقة | من لوحة المنصة (`شركة جديدة`) ومن `POST /platform/tenants`. الباقة تحدد أقصى عدد فروع | `test_platform_onboards_company_with_three_branches_of_three_types`، `test_onboarding_rejects_more_branches_than_plan` |
| إدارة الفروع | إضافة وتعديل وإيقاف من صفحة «الشركة والفروع». الحد من الباقة على الخادم، ورمز الفرع فريد | `test_branch_create_respects_plan` |
| الخدمات والأقسام | لكل نوع نشاط (أطفال/رجالي/نسائي). المدة، والزيارة المنزلية، وعدم تكرار الاسم داخل القسم | `test_duplicate_service_name_in_category_is_a_clear_error` |
| **الأسعار بتاريخ سريان** | كل سعر صف له [من، إلى). التغيير يغلق القديم ويفتح الجديد. لا تعديل بأثر رجعي، وقيد في قاعدة البيانات يمنع التداخل، وسعر خاص لفرع يتقدم على السعر العام | `test_price_change_never_alters_the_past`، `test_database_rejects_overlapping_prices` |
| الموظفون والمهارات | الفروع اللي بيشتغل فيها والخدمات اللي بيعملها. مدير الفرع يرى موظفي فرعه فقط. حد الباقة | `test_staff_with_branches_and_skills_and_plan_limit` |
| العملاء والمستفيدون | ولي أمر + أطفال (أو العميل نفسه). رقم كويتي موحّد، ورقم فريد داخل الشركة، وبحث بالاسم أو الرقم أو اسم الطفل. موافقة واتساب منفصلة عن موافقة التسويق | `test_guardian_with_two_children` |
| الباقات والاشتراك | أساسي / احترافي / سلاسل (من التصميم المعتمد). صفحة اشتراك للشركة، وتعديل الباقات من المنصة، وتغيير الباقة أو الحالة بسبب مسجل في التدقيق، ومنع التخفيض تحت الاستخدام الحالي | `test_platform_changes_plan_with_reason_and_blocks_downgrade_below_usage` |
| **دومين لكل شركة (D-005)** | رابط فرعي تلقائي ودومين خاص حسب الباقة. الخادم يحدد الشركة من الدومين، والـPWA على دومين الشركة لا يعرض غيرها | `tests/test_domains.py` (4) + اختبارات Flutter |
| العزل | لا يمكن ربط موظف بفرع أو خدمة شركة أخرى، ولا رؤية عملائها | `test_isolation_for_phase2_data` |
| الواجهة | مبنية على نظام التصميم المعتمد نفسه (CSS منسوخ كما هو، خط Alexandria، الأيقونات، ثيم لكل نشاط)، عربي/إنجليزي | اختبار متصفح: 16 لقطة |

**النتيجة:** 66 اختبار Backend + 5 Frontend + 5 Flutter، كلها ناجحة.
