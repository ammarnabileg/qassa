## معايير قبول المرحلة 1 (قابلة للفحص)

1. `cd backend && pytest` → 43 passed.
2. مستخدم شركة A يرسل `X-Tenant` لشركة B → 403.
3. قيد يدوي على حساب ذمم العملاء → 422 `je_control_account`.
4. نفس `Idempotency-Key` مرتين → قيد واحد، ورأس `Idempotent-Replay: true`.
5. `UPDATE accounting_journalline …` على قيد مرحّل من psql → خطأ.
6. `python manage.py seed_dev` مع `QASSA_ENV=production` → يرفض.
